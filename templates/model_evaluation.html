The Three-Way Split Architecture

LOCKBOX RULES
Partition Role & Responsibilities Evaluation Frequency
Train (70%) Fit model weights, coefficients, split nodes Every training iteration
Validation (15%) Hyperparameter tuning, pruning, early stopping Multiple iterations per experiment
Test (15%) Lockbox: Unbiased real-world risk estimate Strictly once on final candidate

The Golden Rule of Testing:

The test set must be held out from every modeling decision. If any step (feature selection, scaler fitting, threshold selection) consults test data, your reported metric is an optimistic illusion.

Three Common Data Leakage Pitfalls

PREVENTION

1. Preprocessing Leakage

Fitting scalers or encoders on the entire dataset prior to splitting. Always fit exclusively on the training partition and call transform() on validation and test sets.

2. Target Leakage

Using features that inadvertently encode the target label (e.g. downstream warehouse quality inspection timestamps not available during cold storage transit).

3. Hyperparameter Snooping

Repeatedly testing configurations against the test set and selecting the best one. This snooping produced the +{{ result.split.optimistic_bias }} pts artificial bias shown above.

Why Nested Cross-Validation is Essential

DOUBLE LOOP

When you optimize hyperparameters on a standard k-fold cross-validation loop and report the winning score, that score is optimistically biased due to selection bias (the "Winner's Curse").

CV Approach Outer Loop Role Inner Loop Role Reported Score
Non-Nested CV None (Single loop) Tuning + Evaluation combined {{ result.cv.non_nested_score }}% +{{ result.cv.selection_bias }} pts Bias
Nested CV Unbiased Performance Estimation Hyperparameter Optimization {{ result.cv.nested_mean }}% Unbiased

Nested Cross-Validation Execution Sequence:

• Outer Loop (k = 1 to 5): Splits data into 5 outer folds to measure unbiased generalization performance.
• Inner Loop (Folds 1 to 3): Further splits each outer training set into 3 inner folds to select optimal hyperparameters (e.g. max depth, minimum split samples).
• Model Fit & Evaluation: Retrains the chosen model on the full outer training split and evaluates it on the untouched outer test fold.

Regression Metric Suite Comparison

FORMULAS
Metric Mathematical Description Outlier Robustness Best Used When
RMSE Square root of mean squared error Low (Squaring) Large errors carry disproportionate disaster
MAE Mean of absolute errors High (Linear) Noisy sensor bursts & glitches exist
MAPE Mean absolute percentage error Moderate Intuitive percentage accuracy for business
R² Score Proportion of variance explained Moderate Benchmarking against baseline mean model

Regression Error Formulations:

• RMSE: √( Σ (Actual − Predicted)² / n ) • Quadratic penalty, highly sensitive to extreme spikes.
• MAE: Σ |Actual − Predicted| / n • Linear penalty, robust to sensor telemetry noise.
• MAPE: (100% / n) × Σ |(Actual − Predicted) / Actual| = {{ result.regression.clean_mape }}%
• R² Score: 1 − (Residual Sum of Squares / Total Sum of Squares) = {{ result.regression.clean_r2 }}

Selecting Between RMSE and MAE

DECISION GUIDE

Choose RMSE When:

An error of 20 units is 4 times worse than an error of 10 units. For example, in fruit refrigeration, exceeding critical temperature thresholds by 5°C causes immediate product spoilage, demanding high penalties on large deviations.

Choose MAE When:

Sensor hardware occasionally transmits noise bursts or telemetry drops. MAE evaluates the median expectation and prevents sporadic outlier spikes from distorting model selection.

Why 0.70 Must Mean "70% Likely"

DECISION THEORY

In supply chain logistics, decisions require computing expected financial loss: Loss = P(Spoiled) × Cost(Spoilage) − [1 − P(Spoiled)] × Cost(Inspection). If a model predicts 0.70 but the true empirical frequency is only 45%, cost-optimal thresholding breaks down.

Calibration Formulations:

• Platt Scaling: P(Good | score) = 1 / [1 + exp(A × score + B)] • Fits a parametric sigmoid on model margin scores.
• Isotonic Regression: Fits a non-parametric monotonic step function without assuming a fixed sigmoid curve.
• Brier Score Loss: (1 / n) × Σ (Predicted Probability − Actual Label)² • Lower score indicates sharper, more reliable calibration.

The Bergstra & Bengio Theorem (2012)

THEORETICAL PROOF

In almost all real machine learning models, only a small subset of hyperparameters strongly influence the objective function (e.g. learning rate and tree depth).

Why Random Search Beats Grid Search:

For a budget of 16 evaluations over two parameters where only one parameter is dominant:
• Grid Search (4×4): Tests only 4 distinct values of the dominant parameter.
• Random Search: Tests 16 distinct values of the dominant parameter, exploring the true response surface far more efficiently.

Bayesian Optimization Mechanics

GP SURROGATE

1. Probabilistic Surrogate (Gaussian Process)

Models the unknown black-box validation score with estimated mean μ and epistemic uncertainty band ±2σ for every candidate hyperparameter.

2. Acquisition Function (Upper Confidence Bound)

Balances Exploitation (regions with high expected score) and Exploration (unexplored regions with high uncertainty). Next query point = depth {{ result.search.next_query_x }}.

McNemar's Test for Classifiers

DISCORDANT PAIRS

When comparing two classifiers evaluated on the exact same test records, independent two-sample tests are invalid due to paired dependencies. McNemar's test isolates discordant predictions:

Contingency Cell Description Count
Agreement Cells (a, d) Both models agreed (both correct or both wrong) {{ result.significance.n_a + result.significance.n_d }}
Cell b Logistic Regression correct, Random Forest wrong {{ result.significance.n_b }}
Cell c Logistic Regression wrong, Random Forest correct {{ result.significance.n_c }}

Edwards Continuity-Corrected Chi-Square:

• Formula: χ² = (|b − c| − 1)² / (b + c) = {{ result.significance.chi2_stat }}
• Significance: p = {{ result.significance.p_val_mcnemar }} (p < 0.001) • The superiority of Random Forest is statistically significant and not random chance.

1. Resampling Strategy

Draw B = 1000 bootstrap replicates of test indices with replacement and evaluate Δ on each replicate.
